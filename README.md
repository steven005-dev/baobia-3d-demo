# baobia-3d-demo

## Présentation

Ce projet propose une représentation 3D interactive accessible depuis un navigateur web pour visualiser et présenter le concept de BAOBIA.

## Fonctionnalités

- Visualisation d'une scène 3D interactive.
- Navigation et exploration de l'environnement 3D (rotation, zoom, déplacement via souris/tactile).
- Présentation visuelle des éléments de la maquette BAOBIA.
- Interaction avec les éléments 3D via sélection au clic et affichage de description.

## Technologies utilisées

- HTML5 / CSS3
- JavaScript (ES Modules)
- WebGL via [Three.js](https://threejs.org/) et OrbitControls

## Lancer le projet localement

```bash
cd /home/runner/work/baobia-3d-demo/baobia-3d-demo
npm install
python3 -m http.server 8000
```

Puis ouvrir <http://localhost:8000> dans un navigateur moderne.
